# Changelog

All notable changes are recorded here.

## 1.0.0 — 2026-11-05

- Correct conventional versus HC3 OLS inference and regression explanations.
- Identify uploads by content and invalidate state after changed or failed replacements.
- Use participant-level bootstrap confidence intervals for temporal medians.
- Implement ICC(A,1) absolute agreement and distinguish single-observation SEM from change-score uncertainty.
- Correct Dunn comparisons and unify independent-group test selection.
- Correct correlation filtering, colour scales, and figure downloads.
- Add synthetic numerical regression tests, a Streamlit smoke test, and CI for Python 3.11 and 3.12.
